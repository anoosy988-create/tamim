# 🛡️ لوحة تحكم Cypher Security

مجلد مستقل بالكامل — تقدر تشغّله **داخل البوت** أو على **استضافة ثانية** بدون ما يكون جنبه أي ملف من ملفات البوت.

---

## الملفات

```
panel/
├── standalone.js        ← نقطة التشغيل على استضافة ثانية
├── server.js            ← الداشبورد نفسه (مشترك بين الوضعين)
├── package.json         ← كل الاعتماديات
├── .env.example         ← انسخه إلى .env واملأه
├── lib/
│   ├── bot-context.js   ← يبني عميل Discord + الصلاحيات + الإعدادات
│   ├── db.js            ← موديلات Mongo (مولّدة من index.js)
│   └── protections.js   ← شكل الحمايات والمقاييس (مولّدة من index.js)
└── public/              ← الواجهة (app.js / style.css / index.html)
```

ما فيه أي `require('../')` — المجلد **مكتفّي بذاته**.

---

## ⚠️ اقرأ هذا قبل ما تنشر: توكن واحد = اتصال واحد

ديسكورد يسمح لـ **عملية واحدة فقط** تتصل بكل توكن.

| الحالة | وش تسوي |
|---|---|
| الداشبورد على نفس سيرفر البوت | نفس `DISCORD_TOKEN` عادي ✅ |
| الداشبورد على استضافة ثانية **والبوت شغّال** | **لازم توكن بوت ثاني** ⚠️ |

لو استخدمت نفس التوكن في مكانين، الثاني **يطرد** الأول من الاتصال والبوت يطلع.
`standalone.js` يفحص هالشي ويقول لك صراحةً بالخطأ.

## 🚀 التشغيل على استضافة ثانية

### 1) جهّز الملفات
انسخ مجلد `panel/` كامل (كل شي جوّاه) وارفعه للاستضافة.

### 2)Environment variables
انسخ `.env.example` إلى `.env` واملأ:

| المتغيّر | من وين |
|---|---|
| `DISCORD_TOKEN` | توكن البوت (أو بوت ثاني — انظر التحذير فوق) |
| `OWNER_IDS` | ايدي المالك/الستريتر، لو أكثر من واحد افصلهم بفاصلة |
| `MONGO_URI` | **نفس** رابط MongoDB حق البوت (عشان يقرأ نفس الإعدادات) |
| `CLIENT_ID` / `CLIENT_SECRET` | Discord Developer Portal → OAuth2 |
| `DASHBOARD_REDIRECT_URI` | لازم يطابق المسجّل في البورتال **بالضبط** |
| `PORT` | منفذ الاستضافة (Railway/Render يحطّه لحاله) |

### 3) ثبّت وشغّل
```bash
npm install
npm start
```

عنده يطبع:

```
  ╔══════════════════════════════════════╗
  ║   ✅ الداشبورد شغّال (Standalone)     ║
  ╚══════════════════════════════════════╝
     المنفذ   : 10000
     التوكن   : MyBot#0001 (123...)
     المالك   : 1364...
```

## 🔒 مين يشوف وش

| الحاجة | القاعدة |
|---|---|
| شفافية الدخول | تسجيل دخول Discord (OAuth) إجباري — ما في صفحة بدون جلسة |
| **عزل السيرفرات** | كل مستخدم يشوف **بس** السيرفرات اللي عنده فيها صلاحية إدارة حقيقية (مالك/Administrator/رتبة فوق البوت/ستريتر) |
| فحص كل طلب | `requireGuild()` يعيد التحقق من الصلاحية في **كل** طلب — ما يعتمد على الجلسة وحدها |
| سيرفرات OAuth | تنعرض بس إذا OAuth قال `hasAdministrator` **و** البوت داخل السيرفر |
| إلغاء الوصول | `authorized: false` في قاعدة البيانات يقفل الحساب فوراً |
| الوايت ليست | راعي البوت أو راتب السيرفر فقط |

**ما أحد يقدر يشوف سيرفرات أحد ثاني** — القائمة تنبنى من `canManage()` على بيانات البوت الحية، والقائمة الخام من OAuth ما تنرجع بالرد.

## 🔗 مع البوت (الوضع الافتراضي)

لو ما نسخت المجلد للاستضافة ثانية، الداشبورد يشتغل **جوّه البوت**:

```js
// index.js — موجود أصلاً
const DASHBOARD_PATHS = ['./panel/server.js', ...];
setupDashboard(app, dashboardDeps());
```

في الوضع هذا كل شي يكون مربوط: وحدة التكتات شغّالة، والإعدادات مشتركة في نفس الذاكرة.

الوضع المستقل أخف: **التكتات معطّلة** (ما فيه وحدة التكتات في مجلد الداشبورد) — لو حاولت تحفظها يطلع لك تنبيه واضح بدال خطأ 500.

## 🔄 بعد ما تعدّل `index.js`

`lib/db.js` و `lib/protections.js` **مولّدين** من `index.js` (نسخة حرفية) عشان ما يختلفون:

```bash
node tools/sync-panel-lib.js
```

تشغّلها بعد ما تغيّر الموديلات أو شكل الحمايات في البوت.
